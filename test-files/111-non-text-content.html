SC 1.1.1 Non-text Content

Success Criterion: All non-text content that is presented to the user has a text alternative that serves the equivalent purpose.

Failures (Common Techniques)

F30: Text Alternative is not an Alternative (Filename)

The alt text provides no information about the image content, only the filename.

F30: Text Alternative is Placeholder Text

The alt text uses generic placeholder words like "image" or "photo".

F65: Missing Alt Attribute

The image tag completely lacks an alt attribute. Screen readers may read the filename.

F39: Non-Null Alt for Decorative Image

This image is purely decorative (a spacer) but has alt text, forcing screen readers to announce it.

F3: Information Conveyed by CSS Image Only

The warning icon is inserted via CSS. It has no text alternative in the DOM.
