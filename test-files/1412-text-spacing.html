SC 1.4.12 Failures: Text Spacing

When the text spacing styles are applied, the text in the red boxes should break (clip or spill out).

Clipped Content (Fixed Height)

This text is inside a container with a fixed height of 60px and overflow: hidden. When you apply the WCAG text spacing requirements (line-height: 1.5, letter-spacing: 0.12em), this text will expand vertically. The bottom lines should get cut off, making them unreadable.

Overlap Risk (Fixed Height)

This container has a fixed height but visible overflow. Expanded text will spill out.

Underlying Content: If the text above spills out, it will overlap this sentence, making both unreadable.

Passing Example (Fluid Height)

This container uses height: auto. No matter how much spacing you add, it will grow to fit the content. This is the correct way to build accessible layouts.
